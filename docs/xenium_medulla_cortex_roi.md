# Xenium medulla/cortex ROI

`metadata/xenium_medulla_roi_coordinates.csv` contains the manually defined medulla polygon used for Xenium medulla-versus-cortex relative-abundance analyses.

Cells inside this polygon are assigned to `Medulla`. Cells outside this polygon are assigned to `Cortex`.

The coordinate system is expected to match the cell centroid coordinates in the deposited Xenium `cells.csv.gz` file.
