# Xenium Explorer cell group annotations

`metadata/xenium_explorer_cell_group_annotations.csv` is the custom cell-group file used to visualize annotated fetal ovary Xenium cells in Xenium Explorer.

To reproduce the Xenium Explorer visualization:

1. Download and unzip the full Xenium output bundle.
2. Open the dataset in Xenium Explorer by selecting `experiment.xenium`.
3. Import `metadata/xenium_explorer_cell_group_annotations.csv` as a custom cell-group file in the Cells layer.
4. Select the imported cell group set to view the manuscript cell annotations and colors.

The CSV uses Xenium cell IDs from the deposited Xenium output bundle and should be used with the matching Xenium dataset.
